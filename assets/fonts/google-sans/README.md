# Google Sans assets

CAMS uses this folder as the single font entry point.

The active stylesheet is:

- `google-sans.css`

It currently loads Google Sans from Google's official font CDN and prefers a locally installed Google Sans font when available.

If you want a fully self-hosted build, download the official Google Sans bundle from Google Fonts, place the licensed font binaries in this folder, and update only the `src:` declarations in `google-sans.css`.

Expected family name throughout CAMS:

`Google Sans`
